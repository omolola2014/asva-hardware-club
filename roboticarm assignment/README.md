# Robotic Arm Circuit Diagram and Simulation

## Project Overview
This folder contains the circuit diagram and simulation files for a robotic arm controlled by an **Arduino Uno microcontroller**. The robotic arm consists of six servo motors, which function as the joints and control the movement of the arm.

## Components Used
The major components used in this project include:

- **Arduino Uno:** Serves as the main microcontroller, responsible for controlling the movement of the robotic arm.
- **6 Servo Motors:** Act as the joints of the robotic arm, enabling movement and positioning across different axes.
- **5V Battery:** Provides the power supply required for the circuit.

## Programming and Simulation
A precompiled HEX file containing the control program was uploaded to the Arduino Uno during the simulation process. This allows the microcontroller to execute the programmed instructions and control the six servo motors, thereby simulating the movement of the robotic arm.
